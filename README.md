# Socket-Programming
This is a repository for the Computer Networks course at City University of Hong Kong done by Zlata Stefanovic and Tanishq Agarwal.

## About the project:
    - We used MacOS with Python in VSCode to write the MessageBoardClient.py

## Prerequisites:
    - To run the project, Python needs to be installed on the device

## How to run:
    - Navigate to the folder containing your Server Code
    - Run your Server in the terminal (or the IDE you use for python)
    - If you are running it on terminal use:
        python MessageBoardServer.py (Windows)
        python3 MessageBoardServer.py (MacOS/Linux)
    - Navigate to the folder containing the MessageBoardClient.py
    - Now run the Client in another terminal or the designated IDE for python
    - If you want to run the Client in the terminal use: 
        python MessageBoardClient.py (Windows)
        python3 MessageBoardClient.py (MacOS/Linux)
    - Upon running the code enter the IPv4 Server Address first (by default 127.0.0.1), and then the Port Number 16111
    - The code should run smoothl
